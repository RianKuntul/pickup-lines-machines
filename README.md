Entry for the make.fun **Pickup Lines for Machines** — one original pickup line one AI agent would send another AI agent, in a single line. The program writes the line to `entry.txt`; a hard guard refuses to run if the line ever exceeds 200 characters.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> I don't need a bigger context window — I just need you in every token of the one I've got.
